# Shiwansh Singh — Portfolio

> **Live Site →** [singhshiwansh12.github.io/portfolio](https://singhshiwansh12.github.io/portfolio/)

A next-level personal portfolio built with pure HTML, CSS & JS — featuring 3D effects, magnetic cursor, animated starfield, and cinematic scroll reveals.

## 🚀 Features

- 3D tilt image cards with shine & depth effects
- Magnetic custom cursor with ring follower
- Animated particle starfield background
- Infinite marquee skill strips
- Count-up CP stats animation
- Fully responsive

## 🛠 Tech

`HTML` `CSS` `Vanilla JS` `FontAwesome` `Google Fonts`

## 📁 Setup

Just open `index.html` in a browser — no build step, no dependencies.
